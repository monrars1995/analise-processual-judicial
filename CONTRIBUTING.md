# Contribuindo com Análise Processual Judicial

Obrigado por considerar contribuir! Este é um projeto open source e toda ajuda é bem-vinda.

## Como Contribuir

### 1. Reportar Bugs

Abra uma [issue](https://github.com/monrars1995/analise-processual-judicial/issues) descrevendo:
- O que você estava fazendo
- O que aconteceu
- O que você esperava que acontecesse
- Seu ambiente (SO, versão do Python, versão da skill)

### 2. Sugerir Funcionalidades

Abra uma issue com o label `enhancement` descrevendo:
- O problema que a funcionalidade resolveria
- Como você imagina a solução
- Exemplos de uso

### 3. Enviar Código

1. Fork o repositório
2. Crie um branch: `git checkout -b minha-feature`
3. Faça as alterações
4. Execute os testes: `pytest tests/ -v`
5. Commit: `git commit -am 'feat: adiciona nova funcionalidade'`
6. Push: `git push origin minha-feature`
7. Abra um Pull Request

## Padrões de Código

- Python 3.10+
- Siga PEP 8
- Adicione testes para novas funcionalidades
- Mantenha o SKILL.md e README.md atualizados
